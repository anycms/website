Rust 静态网站生成器

AnyCMS SSG 把 WASM 插件作为构建管线的主线——内容发现、Markdown 渲染、模板上下文、 SEO 与资源处理的每个阶段都可被 hook。输入 Markdown + KDL，输出可直接部署的静态站点。

开始使用 阅读文档
bash — anycms 
# 三步生成你的第一个站点
$ anycms init my-site      # 生成站点骨架
$ cd my-site
$ anycms build             → public/
$ anycms serve             # http://127.0.0.1:1111 实时热重载

一切皆可扩展

对标 Hugo / Zola 的全部常规能力，外加一套贯穿构建管线的 WASM 插件生态。

WASM 插件生态

10 个 Layer-1 管线 hook + 5 个 Layer-2 业务域，从 Markdown 渲染到 SEO、sitemap、feed 全阶段可 hook。

主题与 overlay

三级回退：site > theme > 内置。site 模板 / 静态 / Sass 覆盖主题同名文件，params 可主题化。

纯 Rust 资源管线

grass 编译 Sass、oxc 转译 TypeScript、minify-html 压缩、syntect 代码高亮，零外部依赖。

内容多语言

文件名后缀组织翻译（page.fr.md），per-language URL、hreflang 互链、per-language feeds / sitemap。

权限化沙箱

插件在 extism wasm 沙箱运行，http / 文件读写按 manifest 声明权限强制放行，WASI 文件系统完全禁用。

静态注册中心

插件与主题从一个带 index.json 的静态目录分发，托管在任何静态服务上，无需动态服务器或数据库。
