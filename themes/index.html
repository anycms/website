    三个官方主题随仓库发布，分别面向博客、文档与作品集。它们既是开箱即用的设计，也是主题契约的参考实现。

    portfoliogallerylanding

    安装主题

    anycms theme install ../themes/ink --root ./my-site

    然后在 site.kdl 中启用，并删除 site 自带的 templates/ 与 sass/ 让主题接管（见快速开始）：

    theme "ink"

    主题契约速览

    每个主题是一个 bundle：theme.kdl manifest（含 engine-version、params 声明）+ 必需的 templates/ + 可选 static/ / sass/。详见主题文档。

    本官方网站不使用任何主题——它自带 templates/ 与 sass/，完全自包含。这也是一种合法的用法：当你想要完全定制的设计时，直接在 site 内写模板即可。
